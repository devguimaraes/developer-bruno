# 🚀 Guia Oficial Antigravity

Parabéns por adquirir o **Antigravity Config Pack**! Você agora tem em mãos o framework definitivo para configurar suas IAs e garantir um desenvolvimento de software de elite.

## 📦 Conteúdo do Pacote

1. `GEMINI.md`: O cérebro da operação. Regras curtas e grossas para manter o contexto limpo.
2. `GEMINI-verbose.md`: O manual de instruções detalhado. Quando a IA precisar de contexto profundo, ela lerá este arquivo.
3. `commands/*.toml`: Seus superpoderes. Workflows pré-configurados para automatizar tarefas repetitivas.

## 🛠️ Instalação

1. Copie o arquivo `GEMINI.md` para a pasta `.github/` ou `.cursor/` ou a raiz do seu projeto, onde sua IA costuma ler as instruções globais.
2. Copie `GEMINI-verbose.md` para a mesma pasta.
3. Se você usa uma ferramenta que suporta workflows em `.toml` (como este agente), coloque a pasta `commands/` em `.agent/workflows/` ou equivalente.

## ⚡ Como Usar

### No Dia a Dia

Sempre que iniciar um chat, a IA lerá o `GEMINI.md` e assumirá a persona de planejador sênior.

### Comandos Especiais

No chat, digite:

* `/typescript`: Para carregar regras estritas de TS.
* `/react`: Para carregar as melhores práticas de componentes.
* `/reviewing-code`: Para pedir uma revisão de código implacável.

## 🚀 Workflows

Execute os comandos TOML para orquestrar tarefas complexas:

* `create-feature`: Criação de features ponta-a-ponta com planejamento obrigatório.
* `investigate`: Mapeamento do projeto antes de botar a mão no código.
